A research fork, not a portability promise.

    
This is an AI-assisted research fork of jank, exploring an experimental wasm64 / Emscripten AOT pipeline. It is not general jank Wasm support and this is not a browser REPL: the program was compiled before deployment.

    
The demo uses explicit static roots and a private Binaryen spill transform. Ordinary unrooted startup still fails and general GC safety is unproven. The runtime now roots thrown jank objects and errors; arbitrary native exceptions with GC-managed fields are not covered.
