Build locally · run in a browser

Try it in the browser.

This is an ahead-of-time (AOT) build, not a browser REPL. Edit your jank sources locally, compile them, then serve the resulting JavaScript and Wasm.

Browser requirements

You need memory64 (wasm64) and Wasm exceptions. Chrome works (tested with Chrome 156 without experimental Wasm flags). Safari likely will not; support varies by engine and version. If the live example fails, inspect its runtime diagnostics and try current Chrome.

Use HTTP, not file://. Serve .wasm with application/wasm. This single-threaded demo does not require COOP/COEP headers.

Build the example

On Linux x86_64, have Docker, Python 3, curl, tar and Git available. The driver creates the jank-host-build Ubuntu 24.04 container and installs pinned compiler prerequisites there. SDK downloads and build products stay in ignored experiment directories. A clean bootstrap can take about 17 minutes; existing prerequisites are reused.

git clone https://github.com/h0rv/jank-wasm
cd jank-wasm/experiments/zig-wasm
./jank-build build examples/hello-cljc
./jank-build serve --port 8765 examples/hello-cljc

Open http://127.0.0.1:8765/. build builds both native and Wasm outputs; there is no build browser subcommand. serve serves existing Wasm files until Ctrl-C; it does not build or open a browser. run browser opens Chrome and keeps its server running.

Your own project

Create my-app/src/hello/core.cljc with a hello.core namespace and a -main function. Add my-app/jank-build.json:

{
  "name": "my-app",
  "main": "hello.core",
  "jank": "src",
  "expect": ["hello: checks passed"]
}
  • name: unique safe output name; defaults to the project directory name.
  • main: required namespace whose -main runs.
  • jank: source directory inside the project; defaults to src.
  • expect: required nonempty exact output lines, or an object with native, node and browser line lists. The checker requires these plus exit 0.
  • zig: optional project-relative Zig source file. Omit it for pure jank; Zig is not what enables the Wasm build.
  • wasm_check: defaults to single; spike-continuous is the research spike’s specialized 20-entry checker, not a generic project setting.
./jank-build build my-app
./jank-build serve my-app

Use the example’s platform layer for browser DOM output versus native/Node stdout, with #?(:wasm … :native …). Generic stdout is displayed by the generated page too. Outputs are under artifacts/app/<name>/wasm/ and native/.

Know the limits

This AI-assisted research fork is not general jank Wasm support. The Emscripten pipeline uses static roots and a private Binaryen transform; ordinary startup and general GC rooting are not solved. The runtime roots thrown jank objects and errors, but not arbitrary native exceptions with GC-managed fields. No runtime eval, browser REPL, general browser API layer or thread support is supplied.
