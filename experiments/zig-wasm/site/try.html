Build

You write jank locally, compile it ahead of time, then serve the generated JavaScript and Wasm. Nothing is compiled in the browser.

Browser

The browser needs memory64 (wasm64) and Wasm exceptions. Chrome 156 runs it without flags. Safari probably will not, and support varies by engine version. If the live example fails, open its runtime log.

Serve over HTTP, not file://, with .wasm as application/wasm. The demo is single-threaded, so COOP/COEP headers are not needed.

Build the example

You need Linux x86_64 with Docker, Python 3, curl, tar and Git. The driver builds a jank-host-build Ubuntu 24.04 container and installs pinned compilers in it. Downloads and outputs stay in ignored directories. A clean build takes about 15 to 20 minutes; later builds reuse the toolchain.

Then open http://127.0.0.1:8765/. build produces native and Wasm outputs; there is no build browser subcommand. serve serves files that already exist until Ctrl-C, and does not build or open a browser. run browser opens Chrome and keeps its server running.

Your own project

Create my-app/src/hello/core.cljc with a hello.core namespace and a -main function, then add my-app/jank-build.json:

KeyMeaning
nameOutput name. Defaults to the project directory name.
mainRequired. The namespace whose -main runs.
jankSource directory inside the project. Defaults to src.
expectRequired. Exact output lines, or an object with native, node and browser lists. The check needs these lines and exit 0.
zigOptional Zig source file. Leave it out for pure jank; Wasm builds do not need Zig.
wasm_checkDefaults to single. spike-continuous is the research spike's 20-run checker.

For browser output versus native or Node stdout, copy the example's platform layer, which uses #?(:wasm … :native …). The generated page also shows plain stdout. Outputs go to artifacts/app/<name>/wasm/ and native/.

Limits

The Emscripten build depends on explicit static roots and a Binaryen spill pass. Startup without those roots fails, and GC safety in general is not proven. The runtime roots thrown jank objects and errors, but not native exceptions that hold GC-managed objects. There is no eval, REPL, browser API layer or thread support. The experiment notes have the full requirements and evidence.
